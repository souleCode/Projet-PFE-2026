#### 3.4.2 Gestion des alertes

        Le système doit :

        Générer une alerte en cas d’incident

        Associer un niveau de criticité

        Sauvegarder l’image de l’incident

        Permettre le suivi (nouveau / en cours / résolu)

#### 3.4.3 Tableau de bord

        Le système doit :

        Afficher le nombre d’incidents

        Présenter des statistiques

        Visualiser les caméras actives

        Montrer le statut des Edge devices

#### 3.4.4 Configuration des règles HSE

        Le système doit permettre :

        Définir des règles personnalisées

        Paramétrer les seuils d’alerte

        Définir les zones surveillées

##### 3.4.5 Reporting

        Le système doit :

        Générer des rapports PDF
